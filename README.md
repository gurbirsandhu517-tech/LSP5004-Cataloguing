# LSP5004 V13 — Material-Wise AACR2 All Entries

- No A/B/C/D section selector.
- Material buttons: All Materials, Book, Serial Publication, Map/Cartographic, Motion Picture, Video Recording, Sound Recording, Electronic Resource, Microform.
- Selecting a material type changes the AACR2 treatment; the complete question is still analysed.
- Gemini is primary; Google Search grounding is used as a verification layer with a Gemini-only retry if search grounding is unavailable.
- All justified catalogue entries are generated: main entry, personal/corporate/title/series/uniform-title added entries, and subject access entries when supported.
- No invented bibliographic facts.
- Unlimited catalogue cards and continuation cards.
- 12.5 × 7.5 cm catalogue-card layout with vertical ruling and filing block.
- PDF pages are 12.5 × 7.5 cm.
