# LSP5004 Cataloguing Practice

Version remains 1.0.0.

## Main change
The old multi-field form has been replaced with one large **Complete Question** box.

Workflow:
1. Select Section A/B/C/D.
2. Paste the complete cataloguing question.
3. Click **GENERATE CATALOGUE ENTRY**.
4. Review the generated entry and extracted fields.
5. Click **DOWNLOAD PDF**.

The parser only uses information supplied in the pasted question. Missing information is marked as not supplied and should be verified against authorised course/reference material.

## Run
npm install
npm start

Then open:
http://localhost:3000
